## Findings, including ones that contradict documents written earlier in this same session

1. **The glossary design inverts the measurement it was meant to improve.** Found by Grok. The
   glossary that moved Jev from 0.10 to 0.92 re-teaches the vocabulary `WIKI_SUBJECT` was cut to
   avoid. Verified directly: **7 of 13 glossary terms appear in
   `/Users/michaelboscia/projects/mneme-bosciamem/_index.md`**, and the map's first line
   (`# bosciamem wiki index (20 pages, 4712 evidence cards...`) contains four of them. Every
   delivered-arm prompt carries that map. The existing regex does not match the map, by design,
   and `wiki-controls.py` refuses to run if it ever does. The proposed fix would have made the
   delivered arm vanish, which is the identical defect Grok caught once before in this same file.

2. **A confidence gate was cited for a primitive that has none.** The wiring brief's Finding 4
   argues confidence is usable as a gate. Those numbers are `choice.confidence`. A `noul` answer
   is `{"type": "noul", "noul": 0.41}` with no confidence field, and the plan used `noul`.

3. **The experiment was missing the arm that decides the question.** Found by DeepSeek. The
   comparison run was Jev-with-glossary against the incumbent regex. The arm never run is the
   regex improved by the same jargon knowledge the glossary supplied. Both of the regex's
   observed failures have free deterministic fixes: the misses are term coverage, and the false
   fire is the O-1 surface bug.

4. **Disagreement-only labelling is structurally blind to shared errors.** Found independently by
   Grok and DeepSeek, and demonstrated with this repo's own probe data: "Fix the import in
   `.../mneme-bosciamem/ops/build_index.py`" is a shared false positive where the regex fires and
   Jev returns 0.80. They agree, so it never enters the disagreement set.

5. **O-1 is real but latent, and this session overstated it before measuring.** 4 of 1,610 rows
   diverge, 0.2%, and all four are the same self-referential jury event that quoted the regex
   into the prompt. In ordinary prompts the term appears inside a path, which the paths-only
   surface catches anyway.

6. **The controls and the report compute over different data sources.** `wiki-controls.py` reads
   1,611 PostHog rows and has prompt text. `wiki-usage-report.py` reads 157 events from 99 local
   SQLite ledgers and has no prompt text at all. They join on `$ai_trace_id` for 113 of the
   report's 145 identified rows, 77.9%. So the negative control that certifies the detector was
   established on a population that is not the one the rates are computed over.

7. **The previous handoff's reference sheet was wrong in three places.** `choice` takes `criteria`
   and not `options` (a request with `options` returns 422). There is an official Python SDK,
   `typesafe-sdk`, which no earlier note mentioned. And `jtsang4/jev-cli` is documented as
   defaulting to TypeSafe's own API rather than rejecting it.

8. **There is no official Rust SDK, and four unofficial ones all appeared in September 2026**,
   all 0.1.x, all with double-digit download counts. This is why the panel did not dispute writing
   the client rather than adopting one.

| A `sed` patch silently failed to apply because it anchored at the wrong indent. The run "succeeded" and reported identical results | When a change to an API request should change the request, assert on `input_tokens`.
