## Universal Rules (Always Apply)

**Fully qualified paths only.** Every file reference uses the full absolute path. Relative paths break on compaction, in plan mode, and in inter-agent messages.

**Commit early, commit often.** Every meaningful change goes to git. Don't push without asking.

**Lessons captured in real-time.** When you encounter something lesson-worthy (error, abandoned approach, wrong assumption), add it to the project's `lessons.md` immediately.

**Completion mandate.** Finish 100% of the work. Never suggest leaving work incomplete unless the user explicitly says stop.

**3 failures = auto-escalate.** After 3 consecutive failures on the same problem, STOP and escalate to both Gemini AND Codex via inter-agent MCP. No exceptions.

## Compaction Recovery

After compaction: the `post-compact-recovery.sh` hook injects your session summary automatically.

If context is still insufficient:
```bash
python3 ~/.triumvirate/stenographer/session_log_path.py --recover "$(pwd)" --agent claude
```
Read the file it returns — that's your memory.

## Session Persistence Architecture

```
Stenographer (Ollama, local)     — incremental saves every ~50K tokens
Token Gate (post-tool-use hook)  — triggers stenographer when threshold crossed
Gap-Fill (Gemini CLI, free)      — fills gaps at compaction time
Session Log (rolling, per-transcript) — single file, append-only
```

Session logs are stored in `$AI_MEMORY_DIR/<repo>/` (default: `~/.ai-memory/<repo>/`).
HOME sessions go to `~/.claude/session-logs/`.
